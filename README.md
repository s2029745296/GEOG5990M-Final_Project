GEOG5990M: IMD and NO2 analysis in Manchester

This repository contains a coursework project for GEOG5990M, analyzing the relationship between neighbourhood-level deprivation (IMD) and NO₂ exposure in Manchester. The workflow includes data cleaning, spatial subsetting, aggregation of road-level NO₂ to LSOA level, exploratory data analysis, simple linear regression, and spatial visualization. Data sources include ONS LSOA boundaries, DEFRA modelled NO₂ data, and IMD 2019. All analysis was conducted in Python using GeoPandas, Pandas, and Matplotlib.

All data links have been clearly indicated in the code comments.
